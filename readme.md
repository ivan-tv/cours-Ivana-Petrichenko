## Урок 009

**Операторы в JS**

1. = присваивает значение.
2. == сравнивает без учёта типа.
3. === строгое сравнение.
4. +-конкатенирует строки, прибавляет одно слово к другому.
5. ++- увеличивает на единицу <u>increment</u>
6. -- - уменьшает на единицу <u>decrement</u>
7. && - обозначает - И - ищет первое <u>**_ложное_**</u> значение.
8. || - обозначает - ИЛИ - ищет первое <u>**_верное_**</u> значение.
9. ! - обозначает - НИ- то бишь отрицание, меняет на противоположное значение.
